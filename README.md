# Pengenalan Pola

Beberapa materi yang dipelajari dalam repository ini meliputi:

- Pengolahan data menggunakan **Pandas**
- Operasi dan manipulasi **DataFrame**
- Membaca data dari file CSV dan TXT
- Membaca data dari URL
- Visualisasi data menggunakan **Matplotlib**
- Pengolahan citra menggunakan **OpenCV**
- Operasi pixel dan matriks pada citra
- Konversi citra RGB/BGR dan grayscale
- Dasar-dasar pengolahan dan analisis data
